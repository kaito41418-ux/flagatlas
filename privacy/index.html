1. 我們是誰與本政策的範圍

Flag Atlas 由 Melencolia 開發，提供國旗、首都與地理知識測驗、世界探索及收藏功能。本政策適用於上述離線應用程式，以及 kaito41418-ux.github.io/flagatlas/ 下的隱私與支援網頁。

目前應用程式沒有啟用帳號註冊、雲端同步、使用分析、崩潰回報或廣告服務。我們不透過應用程式將學習紀錄或偏好設定傳送至開發者的伺服器，也不出售個人資料。

2. 儲存在裝置上的資料

為保存進度與設定，應用程式使用裝置上的瀏覽器或 WebView 本機儲存空間。下列資料供裝置上的功能使用，不會由應用程式自動上傳。

  • 測驗成績、錯題、主線進度及複習狀態
  • 每日挑戰結果、解鎖的收藏品及取得日期
  • 尚未完成的測驗與已作答狀態，包括填空題輸入的答案文字
  • 題型、語言、主題、音效、動態效果及圖鑑排序設定
  • 目前分頁的背景紋樣選擇，用於避免連續重複

3. 使用目的與本機保存期間

本機資料用來恢復練習、安排複習、顯示成績與收藏，以及記住設定。資料保留至被應用程式的保存上限替換、由你清除，或由瀏覽器／作業系統清除。

最近練習紀錄最多保存 30 筆，每日挑戰紀錄最多保存 90 筆；這是筆數上限，不是天數。主線進度、錯題、收藏與偏好設定不依這兩項上限自動刪除。

4. 備份與外部連結

你可以在應用程式設定中匯出 JSON 學習紀錄，或選擇備份檔案匯入。匯出內容包括學習紀錄、收藏、測驗設定及可能尚未完成的測驗；語言、主題等部分裝置偏好不在備份中。

備份由你決定儲存或分享的目的地。若選擇雲端硬碟、郵件或其他服務，該服務會依其政策處理檔案。應用程式不會自動將備份交給開發者。

國旗、地圖與音效資產隨應用程式提供，無須呼叫線上地圖或國旗服務。當你開啟資料來源等外部連結時，外部網站可能處理 IP 位址及其他連線資料，其隱私政策另行適用。

5. 網站與第三方服務

本隱私與支援網站由 GitHub Pages 託管。GitHub 會為安全目的記錄及保存訪客 IP 位址，與應用程式的本機學習紀錄分開處理。本網站沒有我們加入的分析程式、追蹤像素、外部字型、廣告或登入表格。

公開聯絡信箱使用 Google Gmail。當你寄信給我們，Google 及你使用的郵件供應商會處理郵件傳遞及儲存所需的資料。網站及郵件供應商依各自政策處理服務紀錄、保存與跨境傳輸。

目前沒有啟用 Firebase、Google Analytics、Crashlytics 或 AdMob 的應用程式資料收集。日後啟用的服務會先在本政策中另行說明。

6. 主動聯絡我們及資料保存

若你主動寄送郵件，我們會收到寄件地址、訊息及你選擇提供的附件，並用於回覆、排解問題、核驗及處理隱私請求。請勿寄送密碼、驗證碼或不必要的個人資料。

支援郵件與附件只保留於處理請求、跟進問題及履行適用法律義務所需的期間；請求處理完畢且不再有上述需要時，我們會刪除或去除其中可識別個人的資料。你也可以要求提前刪除；如有必須保留的資料，我們會說明原因與適用期間。郵件服務供應商的系統紀錄與備份依其政策處理。

7. 資料安全

目前 Android 1.9.0 不申請網際網路權限，停用應用程式自動備份，並限制內嵌 WebView 載入隨附內容。本支援網站啟用 HTTPS。這些措施減少不必要的傳輸，並不表示本機紀錄或匯出的 JSON 檔案已端對端加密。

請妥善保管裝置與備份。裝置安全設定、他人對裝置的存取，以及你選擇的分享或儲存服務，也會影響資料安全。沒有任何系統能保證絕對安全。

8. 檢視、刪除與隱私請求

你可在應用程式內檢視進度或匯出紀錄。刪除 Android 本機資料時，可使用系統「設定 → 應用程式 → Flag Atlas → 儲存空間 → 清除資料／清除儲存空間」，或解除安裝。不同裝置的選項名稱可能不同。

瀏覽器版本可在瀏覽器設定清除此應用程式的網站資料。僅清除快取可能不會刪除儲存的進度。另行匯出的檔案、收件者持有的副本及雲端硬碟備份，需至各目的地另外刪除。沒有自行保存的備份時，本機資料清除無法復原。

目前沒有雲端帳號可供刪除，開發者無法遠端刪除你的裝置紀錄。你可以透過本網站的刪除申請頁聯絡我們，處理你主動寄送的資料或其他隱私請求。寄信提出申請不代表資料已自動刪除。

依適用法律，你可能享有存取、更正、刪除、限制或反對特定處理等權利。請聯絡 kaito41418@gmail.com，我們會依請求內容與必要的身分核驗處理並回覆；你也可向所在地的資料保護主管機關提出申訴。

9. 使用年齡與青少年隱私

Flag Atlas 主要面向 15–22 歲使用者，不以 15 歲以下兒童為目標。這個年齡定位不代表目前需要提供生日或身分證件：目前沒有帳號註冊，也不透過分析或廣告服務收集使用者資料。

帳號與雲端功能仍在準備中。若開放 15–17 歲使用者建立帳號，將先建立獨立的監護人同意、撤回及資料刪除流程，並核實發行地區的適用要求；未完成所需同意前不啟用雲同步。規劃中的可選使用分析僅向 18 歲及以上使用者提供，且須另行自願同意。這些功能目前均未啟用。

若你是家長或監護人，對孩子主動寄送給我們的資料有疑問，可透過上述信箱聯絡我們。

10. 國際資料處理

應用程式不會將本機學習紀錄傳送至開發者的雲端。訪問本網站、開啟外部連結或寄送郵件時，相關服務供應商可能在你所在地以外處理連線或訊息資料，詳見其隱私政策。

未啟用的帳號與雲端服務不適用於目前的處理方式。我們會在啟用前說明實際供應商、資料處理地區與適用的保護安排。

11. 政策變更

我們會因實際功能或資料處理方式的變更更新本頁及日期。啟用帳號、雲端同步、使用分析或廣告前，會先披露所啟用的服務、資料種類、用途、保存與刪除方式，並依適用要求提供告知及選擇。使用目前離線版本，不代表預先同意未來的資料收集。
