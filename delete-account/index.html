Flag Atlas — 帳號與資料刪除

如需刪除 Flag Atlas 帳號或個人資料，請透過本頁聯絡開發者 Melencolia。

目前公開版本將進度儲存在使用者裝置，帳號與雲端同步尚未開放。現在如需刪除本機進度，請使用下方的裝置操作說明。

提出刪除申請

  1. 寄信至 kaito41418@gmail.com，建議使用該帳號的註冊信箱寄送。
  2. 主旨填寫「Flag Atlas — 帳號與資料刪除申請」，說明希望刪除帳號及相關資料，或僅刪除支援往來資料。
  3. 若由家長或法定監護人申請，請註明身分。我們會回覆說明必要的身分與監護權核驗程序。

開啟郵件，申請刪除

按鈕會開啟郵件程式，仍須由你寄出郵件。瀏覽本頁不會提交申請或刪除資料。如未開啟郵件程式，請將上述信箱複製到你使用的郵件服務。

首次來信請勿附上密碼、驗證碼、付款資訊或身分證件。如需要進一步核驗，我們會另外說明。若無法使用原註冊信箱，請在來信中註明。

申請涵蓋的資料

若帳號存在於已開啟雲端服務的版本，帳號刪除申請涵蓋登入帳號、雲端學習進度、自願提供的使用紀錄及相關監護人同意紀錄。另行匯出的備份與本機遊客進度，需要另外刪除。

開發者會人工核驗及處理申請，並回覆處理結果；如有必須保留的資料，會說明原因。寄出郵件不代表資料已立即刪除。本頁提供聯絡申請管道，尚未接通雲端自助刪除。

刪除本機進度

  • Android：系統設定 → 應用程式 → Flag Atlas → 儲存空間 → 清除資料／清除儲存空間，或解除安裝
  • 網頁版：清除你使用 Flag Atlas 的網站資料；僅清除快取可能不會刪除進度
  • 另外刪除匯出的 JSON 備份，以及雲端硬碟或共用資料夾中的副本

沒有自行保存的備份時，本機清除無法復原。清除裝置資料不會自動提交帳號刪除申請。

本網站的隱私

本頁沒有分析、廣告、登入表格或追蹤 SDK。頁面由 GitHub Pages 託管，平台可能為安全目的處理訪客 IP 位址。寄信會將你提供的內容交由 Melencolia 及郵件服務供應商處理。
